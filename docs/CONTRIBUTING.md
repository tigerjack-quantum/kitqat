# Contribution and Development Policy

This document applies to contributors working on the private repository.

## Development model

This project follows a two-stage process:

1. Internal development in a private repository
2. Public release on GitHub under the Apache License 2.0

## Confidentiality

All content in the private repository — code, discussions, issues, and design
documents — is confidential until explicitly released publicly.

Contributors must not:
- share or publish any content from the private repository externally
- disclose implementation details outside the project team
- mirror or fork the private repository in any external system

## Contributions and licensing

By contributing, you agree that:
- your contributions may be included in a future public release
- published code is released under the Apache License 2.0
- maintainers may modify or restructure contributions before publication
- unpublished contributions remain confidential indefinitely unless explicitly released

## Publication process

Only maintainers decide when and whether code is released publicly. The stages are:

1. Internal development
2. Review and integration
3. Public release on GitHub

## Attribution

Contributors retain authorship of their work. 
Significant contributions will be acknowledged in
[CONTRIBUTORS](CONTRIBUTORS.md) or release notes.

## Acknowledgment

By contributing to this repository, you accept the terms described in this document.
